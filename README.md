# bemind homebrew tap

```sh
brew tap kla-bemindlabs/tap https://github.com/kla-bemindlabs/homebrew-tap.git
brew install --cask burrow
```

⚠️ ระหว่าง repo `burrow` ยังเป็น private: ตั้ง `export HOMEBREW_GITHUB_API_TOKEN=<token>`
(token ต้องมีสิทธิ์ repo) ก่อน `brew install` — เมื่อ repo เปิด public แล้วติดตั้งได้ตรง ๆ
